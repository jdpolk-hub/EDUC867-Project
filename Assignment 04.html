Assignment 04 Estimation Functions

Author

Joy Polk

Purpose

The purpose of this assignment is to develop reuseable functions for estimating multiple linear regression models using matrix operations in a Click-to-Run file that can be rendered as HTML and PDF across various operating systems (e.g., Mac, Windows, Linux).

Core: Task 1

In your project repository, write (at minimum) two functions built on the matrix-based approach: a fitting function that takes an outcome and predictors (a matrix or a data structure you document — your design choice) and returns the coefficients, their standard errors, the residual variance, and the fitted values; and a prediction function that takes a fitted result and new predictor values and returns predicted outcomes.

Two reusable functions were developed and saved in R/regression_functions.R. The first, fit_matrix_reg(), estimates multiple linear regression models using matrix calculations. The second, predict_matrix_reg(), generates predicted outcomes from the estimated coefficients and new predictor values.

Core: Task 2

Document both functions with comments stating their inputs, outputs, and assumptions. Someone opening the file cold (for instance, you in November) should know what goes in, what comes out, and what the function assumes about its inputs.

Both functions include comments describing their inputs, outputs, and assumptions. The fitting function accepts a numeric outcome vector and a predictor matrix without an intercept column, which is added internally. The prediction function accepts the fitted model and new predictor values in the same order used during estimation. Both functions require complete numeric data, and the fitting function additionally requires a full-rank design matrix with more observations than estimated coefficients.

Loud failure. Given data containing missing values, or a predictor matrix that is rank- deficient, your functions must fail loudly with an informative error message rather than silently returning garbage — and your document must include tests proving both behaviors: one showing the missing-data refusal, one showing the rank-deficiency refusal, each demonstrating that the error occurs and says something useful.

#Test 1: Missing values
X_missing <- X
X_missing[1, 1] <- NA

missing_error <- tryCatch(
  fit_matrix_reg(y, X_missing),
  error = function(e) e
)

#Display error message
print(conditionMessage(missing_error))
